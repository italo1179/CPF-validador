Validador de CPF em C

Este projeto foi desenvolvido em linguagem C e tem como objetivo validar números de CPF utilizando o algoritmo oficial de verificação dos dígitos verificadores.

O programa recebe um CPF com 11 dígitos, converte os caracteres para valores numéricos e realiza os cálculos dos dois dígitos verificadores. Em seguida, compara os resultados obtidos com os dígitos informados pelo usuário, indicando se o CPF é válido ou inválido.

Funcionalidades
Leitura de CPF pelo teclado.
Conversão de caracteres para números inteiros.
Cálculo do primeiro dígito verificador.
Cálculo do segundo dígito verificador.
Validação completa do CPF.
Exibição do resultado na tela.
Tecnologias Utilizadas
Linguagem C
Biblioteca padrão (stdio.h, stdlib.h, string.h)
Objetivo

Praticar conceitos fundamentais de programação, como vetores, estruturas de repetição, condicionais, manipulação de caracteres e implementação de algoritmos matemáticos.
